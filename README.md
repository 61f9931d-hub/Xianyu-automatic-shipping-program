# 闲鱼自动发货工具

监控闲鱼网页版聊天页，买家拍下并**付款**后，自动在聊天中发送虚拟商品内容（网盘链接 + 提取码）。

- 纯本地运行，无云端依赖，商品数据和登录态均保存在本机
- 自动识别「我已付款，等待你发货」系统消息，排除「待付款」等不可发货状态
- 发货通过**聊天发送消息**完成，不点击「去发货」按钮，适配虚拟商品
- 自动去重：同一会话不会重复发货

## 快速开始

1. 双击 `start.bat`（首次运行会自动创建环境、安装依赖、下载浏览器内核，约 3-5 分钟）
2. 启动后点击 **「登录闲鱼」**，在打开的浏览器窗口中扫码登录，登录后关闭浏览器窗口
3. 在 **「商品管理」** 页新增商品（匹配关键词 + 发货内容）
4. 点击 **「启动监控」**，工具开始每 N 秒扫描一次新付款订单并自动发货

> 提示：登录态会保存在 `data/browser_profile`，下次无需重复扫码（除非闲鱼会话过期）。
> 浏览器策略：程序优先使用系统已安装的 Edge/Chrome（无需下载浏览器内核）；若都没有，才使用内置 Chromium（首次启动时自动下载，已配置国内镜像加速）。

## 商品配置说明

| 字段 | 说明 |
|------|------|
| 商品名称 | 仅用于识别，任意文本 |
| 匹配关键词 | 逗号分隔；聊天/订单内容中出现任一关键词即命中该商品。建议用商品标题中的核心词 |
| 发货内容 | 发送给买家的文本。建议写成一行，如 `链接：https://pan.xxx.com/s/xxx  提取码：abcd` |

未匹配到商品的付款订单会记录为「未匹配」，可在设置页配置「兜底内容」自动发送。

## 常见问题

**Q: 检测不到付款订单 / 页面改版后失效？**
闲鱼网页版会不定期改版。若失效，编辑 `app/config.py` 中的 `PAYMENT_MARKERS`（付款特征文本）、`INPUT_PLACEHOLDERS`（输入框特征）等常量；配合运行日志页观察实际页面文本。也可反馈给我更新。

**Q: 会不会误发给"待付款"买家？**
不会。扫描时会排除包含「待付款」等标记的会话，且要求会话卡片中出现付款特征文本。

**Q: 自动操作有封号风险吗？**
闲鱼没有开放个人自动发货 API，任何自动化工具都有一定风控风险。本工具采用保守策略：间隔默认 60 秒、带随机人工节奏、复用真实登录态。建议小流量使用，避免超大店铺高频操作。

**Q: 浏览器登录后关闭，为什么还要登录？**
闲鱼登录态有有效期，过期后需要重新扫码，程序会弹窗提示。
